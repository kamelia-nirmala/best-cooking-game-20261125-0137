Dapur Sizzle is a one-chef rush kitchen game built for make.fun's "Make the best cooking game" bounty ($250 in USDC). Grab ingredients from the counter, chop lettuce and tomato, grill patties before they burn, assemble dishes on the plate, and serve matching orders at the window before they walk out. A 150-second shift, five recipes, combos for fast service, and a rush hour that tightens every order's patience as levels rise.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with keyboard (WASD / arrows to move, E or Space to use a counter, P to pause, M to mute) or mouse (click a counter to walk to it and use it). No build step, no network requests: game/index.html and its scripts under game/ are the whole game.
